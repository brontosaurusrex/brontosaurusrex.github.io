## Firefox theme syncing with Omarchy

Requires Omarchy 4+ and native Firefox 142+.

1. Install [Omafox in Firefox](https://addons.mozilla.org/en-US/firefox/addon/omafox/).
2. Run in your terminal:

   ```bash
   omarchy pkg aur add omafox
   omafox setup
   omafox status
   ```

Firefox now follows Omarchy theme changes automatically.

If it doesn’t connect initially, restart Firefox once, then run:

  ```bash
  omafox sync
  ```

### For agents

- Use Omafox’s signed extension and AUR helper.
- Run `omafox setup` as the normal user.
- Preserve existing Firefox settings and CSS.
- Verify extension `@omafox` is active and signed.
- Verify the native connection:

  ```bash
  pgrep -af '^/usr/lib/omafox/omafox-native-host'
  ```

### Uninstall

```bash
omafox remove
sudo pacman -Rns omafox
```

Then remove Omafox from Firefox’s `about:addons`.
